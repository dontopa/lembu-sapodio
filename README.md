# Lembu Sapodio 🐄

Laman jualan lembu — lembu korban, akikah & baka. Semua pembelian melalui WhatsApp.

- Static site: `index.html` (tiada build step)
- Logo & variasi: `brand/`
- Tukar nombor WhatsApp: pemalar `WA` dalam `index.html`
- Tambah lembu: array `cows` dalam `index.html`

Gambar stok: Unsplash · Video stok: Mixkit

## Belajar Bersama Sapo (`/belajar/`)

Permainan pendidikan PWA untuk kanak-kanak 4 tahun — 8 game × 3 tahap, suara Bahasa Melayu, bintang & pelekat, zon ibu bapa dengan kemajuan, had masa skrin, boleh main offline.
Buka `/belajar/` dan "Add to Home Screen". Kajian & reka bentuk: `belajar/RESEARCH.md`.
